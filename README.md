# Weblion – EventCrazy / Crazy panel

- `crazy-panel/` – a Crazy Foglaltsági Panel **Statisztikák** moduljának forrása (v1.15.0): `stat.php`, `assets/stat.js`, `assets/stat.css`,
  valamint a meglévő fájlok módosításai különbségfájlként (`patches/`).
- `docs/statisztikak-utmutato.md` – beállítási útmutató (cron, Google Ads-szkript, Meta-token, GA4, Make-mezők).

A fájlok élesben az eventcrazy.hu `wp-content/plugins/crazy-panel/` mappájában futnak (a Crazy Claude-hídon át telepítve).
Titkos adat (kulcs, token) nincs a tárolóban.
